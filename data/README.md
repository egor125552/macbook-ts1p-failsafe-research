# Public evidence data

This directory contains measurement/replay data produced by the investigation, not Apple binaries.

## Files

- `live-snapshot-2026-10-13.txt` — direct read-only SMC snapshot plus scheduler mask captured while the fault was active.
- `ts0p-ts1p-history.csv` — 900 historical sensor records extracted from available PowerLog databases.
- `xppt-xupt-history.csv` — 879 historical final package/utility limit records.
- `budget-history-summary.json` — per-database xPPT summary used during analysis.
- `smc-failsafe-replay.json` — output of the public isolated firmware policy replay.
- `smc-reset-command-replay.json` — output of the isolated diagnostic-command replay.
- `scheduler-mask-transition.txt` — timestamped clean core-mask transition sequence.
- `traces/pi-causal-trace.csv` — full CLPC/PI trace window used for the limiter correlation.
- `traces/clpc-trace.csv` — separate CLPC trace window from the investigation.
- `traces/clpc-unit-window.csv` — short CLPC unit window used when decoding event arguments.

## Time zone

Historical CSV timestamps rendered by this repository use UTC+03, the machine-local offset at the time of capture. The timestamp column explicitly says `time_utc_plus_03` where generated by the public extractor.

## Privacy / redistribution

Database paths were reduced to basenames in the public CSVs. Apple firmware, kernelcache and user files are not present. Raw trace launch-command banner lines were removed before publication; the retained trace rows are kernel events used by the analysis.

## Interpreting the data

Do not use one value in isolation. In particular, xPPT can legitimately vary under other policies. The case documented here is distinguished by the combination of a missing historical temperature signal, `SEB0` input-12 fault, the isolated SMC fail-safe replay and the downstream 2000 mW / SLOWTEMP limiter chain.
